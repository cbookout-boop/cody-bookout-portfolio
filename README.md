# Cody Bookout — Personal Portfolio

An HTML-only portfolio scaffold for Web Development (A).

## Files
- `index.html`: Home
- `projects.html`: Projects / Work
- `about.html`: About / Contact
- `wireframe.png`: Wireframe of all three pages, with planned palette and fonts

## View the project
Open `index.html` in a browser. Use the navigation to visit each page. Keep the three HTML files in the same folder.

## Design plan
Planned colors: warm ivory (#FAF7F0), charcoal (#222222), forest green (#234536), and antique gold (#B6985B). Planned fonts: Georgia for headings and Arial for body text, with serif and sans-serif fallbacks. These choices are planning notes only; no CSS is applied.

## GitHub submission
1. Extract this ZIP file.
2. Create a GitHub repository named `cody-bookout-portfolio`.
3. Upload the contents of this folder to the repository root, including all three HTML files and `wireframe.png`. Upload the extracted files, not the ZIP itself.
4. Commit the files and verify they appear in the repository. Ensure your instructor can access the repository.
5. Copy the repository URL from your browser and paste it into the assignment response box.

A GitHub repository has not been created as part of this download.
